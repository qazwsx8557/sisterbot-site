妹妹助理

家人私用的 Telegram 聊天助理（不對外提供服務）

妹妹助理是一個只供特定家庭成員使用的 Telegram 機器人。除了一般聊天，當使用者把家人的健康檢查報告截圖傳給它時，它會：

  1. 把截圖存到使用者自己的 Google 雲端硬碟，放在它自己建立的資料夾中，並依日期分類；
  2. 整理報告上的數值與前幾天的變化，提供參考說明（不是醫療診斷）。

它只要求 Google 雲端硬碟的 drive.file 權限：只能存取它自己建立的資料夾與檔案，看不到使用者雲端硬碟中的其他內容，也不會分享任何檔案。

隱私權政策

Sister Assistant is a private, family-only Telegram bot. When the user sends screenshots of a family member's health-check reports, it saves them to the user's own Google Drive in a folder it creates (organized by date) and summarizes the values for reference (not medical advice). It requests only the drive.file scope and never shares files. Privacy Policy
